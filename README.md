# MaklyxaTube

Десктопный клиент YouTube для Windows 10 и 11 (x64). Приложение написано на Rust и использует Microsoft Edge WebView2.

## Скачать и запустить

Скачай `MaklyxaTube.exe` из [релизов GitHub](https://github.com/qqew666/maklyxa-tube/releases) и запусти его. Если в системе нет [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), установи его перед запуском.

## Возможности

- Тёмная тема с красным акцентом и фоновое воспроизведение при свёрнутом окне.
- Скрытие рекламных блоков и пропуск рекламных роликов, когда их распознаёт клиент.
- Пропуск спонсорских вставок и саморекламы через [SponsorBlock](https://sponsor.ajay.app/).
- `Shift+F1` показывает и скрывает панель. Кнопка **MT** открывает настройки рекламы и спонсорских вставок, а **⬇ Скачать** сохраняет открытое видео и показывает прогресс.
- При повторном запуске открывается уже существующее окно.
- При сбое подключения отображается кнопка **Повторить**. Приложение также повторяет попытку автоматически через 25 секунд.

Скачанные видео по умолчанию находятся в **Видео → MaklyxaTube**. При первом скачивании приложение загружает официальные версии yt-dlp, FFmpeg и Deno с GitHub, проверяет контрольные суммы и сохраняет инструменты в `%LOCALAPPDATA%\MaklyxaTube\tools`. Для этой загрузки требуется доступ к GitHub. При следующих скачиваниях используются сохранённые файлы.

## Подключение без отдельного VPN

При первом запуске MaklyxaTube пробует открыть YouTube напрямую. Если соединение не проходит или видео долго не загружается, клиент автоматически пробует резервный маршрут через Tor с европейским выходом. Tor используется только для поддерживаемых адресов внутри приложения. Отдельный VPN и свой сервер не нужны.

Первое переключение скачивает около 23 МБ из подписанного [Tor Expert Bundle](https://www.torproject.org/download/tor/), проверяет контрольную сумму и сохраняет пакет в `%LOCALAPPDATA%\MaklyxaTube\tools\tor`. Клиент пробует встроенные мосты Snowflake и obfs4. Подключение может занять несколько минут. Доступность зависит от провайдера и мостов Tor. YouTube может ограничивать работу через некоторые выходы, а скорость может быть ниже.

### Свои маршруты

Если у тебя есть HTTPS- или SOCKS5-прокси, можно выбрать их вместо встроенного маршрута.

На экране ошибки нажми **Настроить маршруты** или открой `%APPDATA%\MaklyxaTube\routes.json`. Укажи адреса доступных тебе прокси за пределами России, сохрани файл и перезапусти приложение. Например:

```json
[
  { "country": "DE", "url": "https://proxy-de.example:443" },
  { "country": "NL", "url": "socks5://proxy-nl.example:1080" }
]
```

Адреса с `.example` приведены для примера. Замени их своими. `country` — двухбуквенный код страны прокси. Если прокси требует авторизации, добавь поля `username` и `password` в локальный файл. Для передачи пароля по зашифрованному соединению используй HTTPS-прокси. Не публикуй этот файл с паролями.

Клиент начинает с первого маршрута, переключается на следующий при сбое и показывает регион в панели **MT**. Если настроено несколько маршрутов, клиент также пытается переключиться после длительной буферизации видео. Если рабочий маршрут не найден, приложение показывает экран ошибки и повторяет попытку через 25 секунд.

## Данные и диагностика

- Настройки — `%APPDATA%\MaklyxaTube\settings.json`. Можно изменить папку скачивания через поле `downloadDir`, пока приложение закрыто.
- Профиль WebView2, включая кэш и вход в аккаунт — `%LOCALAPPDATA%\MaklyxaTube\webview`.
- Журнал — `%APPDATA%\MaklyxaTube\app.log`.

Формат настроек совместим с версией 0.1.2. При запуске используется существующий профиль в папке `webview`. Если этой папки ещё нет, профиль копируется из `%APPDATA%\pywebview`, если он там есть.

## Сборка из исходников

На Windows x64 нужны Rust 1.88 или новее, инструменты сборки Visual Studio с компонентом **Разработка классических приложений на C++** и WebView2 Runtime для запуска. В каталоге проекта выполни:

```bat
build.bat
```

Готовый файл появится в `dist\MaklyxaTube.exe`. Для запуска из исходников используй `cargo run --locked`, для тестов — `cargo test --locked`.

Изменения YouTube могут влиять на распознавание рекламы и скачивание видео. Версии и контрольные суммы инструментов заданы в `src/tools.rs`.
