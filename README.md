# MaklyxaTube

Десктопный клиент YouTube для Windows: своя тёмная тема с красным акцентом,
без рекламы, с пропуском спонсорских вставок и скачиванием видео.

## Возможности

- **Тёмная тема с красным** — оформление как на превью: чёрный фон,
  красный акцент `#ff0033`, красная полоса прогресса и скроллбары
- **Без рекламы** — рекламные блоки страницы скрываются, рекламные ролики
  перематываются на конец автоматически
- **Пропуск спонсорских вставок** — интеграция с базой SponsorBlock:
  вставки «спонсор» и «самореклама» пропускаются сами
- **Фоновое воспроизведение** — звук не обрывается при сворачивании окна
- **Скачивание видео** — кнопка «⬇ Скачать» сохраняет текущее видео в
  `Видео\MaklyxaTube` (через yt-dlp, нужен установленный FFmpeg для склейки)
- **Панель MT** — кнопка «MT» в правом верхнем углу: включение/выключение
  блокировки рекламы и спонсорских вставок

## Скачать

Готовый `.exe` — в [релизах](https://github.com/qqew666/maklyxa-tube/releases).
Просто запусти, установка не нужна.

## Сборка

```bat
build.bat
```

Собирает `dist\MaklyxaTube.exe` через PyInstaller (onefile).

## Запуск из исходников

```bat
C:\Python315\python.exe app.py
```

## Примечания

- Приложение неофициальное; блокировка рекламы нарушает условия YouTube,
  за аккаунт теоретически могут ограничить — используй на свой страх и риск
- Скачивание работает, пока YouTube не меняет защиту; yt-dlp обновляется часто
- SponsorBlock — сторонняя открытая база сегментов
